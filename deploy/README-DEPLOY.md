# انتشار سایت روی سرور واقعی + دامنهٔ اختصاصی

سایت روی **Cloudflare Workers + D1** اجرا می‌شود (همان معماری فعلی پروژه). این سند
قدم‌به‌قدم می‌گوید چطور آن را زنده کنید. حدود ۱۵ دقیقه وقت می‌برد و برای یک مدرسه
با پلن **رایگان** هم کافی است.

---

## ⚠️ اول: دربارهٔ دامنهٔ `rahnama.com`

بررسی کردم:

| مورد | نتیجه |
|---|---|
| وضعیت | **ثبت‌شده — مال شما نیست** |
| تاریخ ثبت | ۱۱ جولای ۲۰۰۳ |
| انقضا | ۱۱ جولای ۲۰۲۹ |
| آخرین تغییر | ۲۷ جولای ۲۰۲۶ |
| نیم‌سرورها | `k.ns.globalcdntech.com` / `l.ns.globalcdntech.com` |

یعنی این دامنه از ۲۰۰۳ دست کس دیگری است و نمی‌توان آن را آزادانه گرفت. برای
استفاده از آن باید با مالکش مذاکره و خرید کنید (معمولاً گران است) — و من هم
نمی‌توانم دامنه بخرم یا ثبت کنم، چون به پرداخت و حساب کاربری نیاز دارد.

**پیشنهاد:** یکی از این‌ها را بگیرید و همان را به سایت وصل کنید. همهٔ کد سایت
طوری نوشته شده که با یک فرمان روی دامنهٔ تازه بنشیند:

```
node deploy/set-domain.mjs rahnama.ir          # یا هر دامنه‌ای که خریدید
node deploy/set-domain.mjs rahnamaedu.ir --www # اگر دامنهٔ اصلی با www باشد
node deploy/set-domain.mjs --show              # نمایش دامنهٔ فعلی
```

این فرمان `CNAME`، همهٔ `canonical`ها، `og:url`، `twitter:image`،
`sitemap.xml`، `robots.txt` و `_headers` را یک‌دست می‌کند.

گزینه‌های در دسترس و ارزان: `rahnama.ir` / `rahnamaedu.ir` / `rahnama-school.ir` /
`hamkardarsi.ir` (دامنهٔ فعلی پروژه).

## گام ۱ — نصب و ورود

```
npm install
npx wrangler login
```

## گام ۲ — ساخت دیتابیس

```
npx wrangler d1 create rahnama-db
```

شناسهٔ خروجی را در `wrangler.jsonc` جای `PUT-YOUR-D1-DATABASE-ID-HERE` بگذارید.

## گام ۳ — رمز مالک و کلید دستیار

```
npx wrangler secret put OWNER_PASSWORD     # یک رمز قوی و تازه
npx wrangler secret put ANTHROPIC_API_KEY  # اختیاری: برای فعال‌شدن دستیار سروری
```

## گام ۴ — انتشار و بررسی

```
npm run deploy
curl https://<نام-شما>.workers.dev/api/health
```

باید `"ok":true` و `"version":"6.0"` ببینید.

## گام ۵ — وصل‌کردن دامنه

۱. دامنه را در Cloudflare اضافه کنید (Add a site) و نیم‌سرورها را در پنل ثبت‌کننده عوض کنید.
۲. Cloudflare ← **Workers & Pages** ← پروژهٔ `rahnama` ← **Settings** ← **Domains & Routes**
۳. **Add Custom Domain** → دامنه‌تان را بنویسید (مثلاً `rahnama.ir`).
۴. صبر کنید تا گواهی SSL صادر شود (چند دقیقه).

> **نکته:** اگر می‌خواهید سایت روی دامنهٔ اصلی بدون `www` باشد، هر دو را اضافه کنید و
> یکی را با **Redirect Rule** به دیگری بفرستید.

## گام ۶ — دادهٔ اولیه

کاربران، تیک آبی و کلاس‌ها همه در D1 ذخیره می‌شوند و نیازی به SQL دستی نیست.
برای ورود اول با ایمیل مالک (`OWNER_EMAIL` در `wrangler.jsonc`) و رمز گام ۳ وارد شوید.

## انتشار خودکار با GitHub

فایل `.github/workflows/deploy-cloudflare.yml` آماده است. در مخزن GitHub این دو Secret را بگذارید:

| Secret | از کجا |
|---|---|
| `CLOUDFLARE_API_TOKEN` | Cloudflare ← My Profile ← API Tokens ← Create Token (قالب *Edit Cloudflare Workers*) |
| `CLOUDFLARE_ACCOUNT_ID` | Cloudflare ← Workers ← سمت راست صفحه |

بعد از آن، هر `git push` روی شاخهٔ `main` سایت را خودکار منتشر می‌کند.

## هزینه و ظرفیت

| مورد | پلن رایگان |
|---|---|
| Workers | ۱۰۰٬۰۰۰ درخواست در روز |
| D1 | ۵ گیگابایت ذخیره، ۵ میلیون خواندن در روز |
| پهنای‌باند | نامحدود |

برای یک مدرسه یا کلاس‌های چندصدنفره کافی است. کلاس زندهٔ بسیار شلوغ (بالای ۵۰ نفر
هم‌زمان) را بهتر است روی پلن پولی یا با Durable Objects اجرا کنید.
